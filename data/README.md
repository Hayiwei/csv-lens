# Sample data

The bundled orders are entirely synthetic, generated by scripts/make_sample.py
with NumPy seed 42. City names are fictional. Amounts are arbitrary currency
units, not real prices or a real business.

- 240 original rows and 8 intentionally repeated rows.
- Missing values are deliberately inserted into city, unit_price, and channel.
- The recorded order_total is retained when unit_price is missing.
- No real people, customer records, or external datasets are used.

Regenerate with: python scripts/make_sample.py
